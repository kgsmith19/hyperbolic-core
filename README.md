# lifeos-ui

Web UI for [lifeos](https://github.com/kgsmith19/lifeos): a React SPA over the
lifeos FastAPI backend (tailnet-only), signed in with Supabase Auth. Browse and
search the entity graph, capture new entities through schema-driven forms,
inspect an entity's edges and full event history, and erase PII (`forget`).

Stack: React 19, TypeScript strict, Vite, Tailwind v4, TanStack Query,
React Router, Vitest + Testing Library, Playwright, oxlint + prettier.

See [AGENTS.md](AGENTS.md) for commands, engineering standards, and deploy.
