# Agentic Command Center — UI

Web UI for [agentic-command-center](https://github.com/kgsmith19/agentic-command-center) (ACC). ACC stays a zero-dependency headless core serving a loopback API; this repo is the modern front end that builds to static files ACC serves same-origin (`--ui-dist`, ADR-0006 there).

Scaffold lands in the first PR.
