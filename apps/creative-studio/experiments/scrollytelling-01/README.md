# Three Living Document prototypes

The runnable static demos are in `demos/living-document/`. Open the hub index with a local static server.

- **Choreographer:** GSAP ScrollTrigger, pinned scroll-scrubbed SVG choreography.
- **Observer:** native IntersectionObserver (Scrollama-style), editorial chapters driving diagram states.
- **Native:** CSS scroll-driven animation, progressive enhancement.

All are illustrative prototypes; no objective winner has been established. Validate actual browsers, reduced motion, keyboard/touch navigation, and performance before adopting a default.
