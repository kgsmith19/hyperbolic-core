# Editorial Lab 02

Three standalone HTML prototypes using native browser APIs, original SVG and CSS. Open `index.html` through a local static server.

- **Kinetic Thesis:** editorial text transitions controlled by button and scroll.
- **Decision Atlas:** interactive priority selection and diagram transformation.
- **Cinematic Atlas:** sticky scroll scenes, orbit transformations and color changes.

These are creative prototypes, not tested production deliverables. Verify keyboard/touch, reduced motion, performance and mobile screenshots before promoting to showcase. No external dependencies.
