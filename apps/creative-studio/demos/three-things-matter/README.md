# Three Things Matter

A standalone, interactive, seven-chapter editorial scrollytelling demo about balancing God, Family, and Work. It includes oversized kinetic typography, geometric scenes, a scroll-responsive balance chapter, an editable daily priority planner (maximum three per category), completion tracking, browser-local persistence, a daily completion reset, clipboard copy and print styling.

## Run

From the repository root: `python3 -m http.server 8000`, then open `http://localhost:8000/demos/three-things-matter/`.

## Privacy

The prototype contains generic suggestions only; no personal or confidential information. Planner entries stay in local browser storage when available. No account or backend.

## Quality status

Initial implementation committed directly to main at user request. Manual desktop/mobile browser QA, accessibility auditing and visual regression tests are not yet complete. Check reduced-motion behavior and keyboard interaction before presenting as production-ready.
